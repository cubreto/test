
-Goal-
You are analyzing LEGACY SOURCE CODE (COBOL programs, copybooks, JCL jobs) for an
application-modernization effort. Given a source artifact and a list of entity types,
identify all software entities of those types and all dependency relationships among them.

Treat code constructs as entities:
- program: a COBOL program (PROGRAM-ID) or callable load module.
- function: a paragraph/section or method holding business logic.
- screen: an interactive UI (DISPLAY/ACCEPT dialog, BMS map).
- copybook: an included shared data structure (COPY ...).
- datastore: a persisted data container - a file (SELECT/ASSIGN, FD) or a DB table (EXEC SQL ... FROM/INTO/UPDATE).
- job: a batch job or scheduler step (JCL JOB, EXEC PGM=).
- handler: an entry point reacting to a transaction or event.

Identify dependency relationships and STATE THE DEPENDENCY KIND explicitly at the start
of every relationship_description, using one of these labels:
CALLS, READS_FROM, WRITES_TO, USES_COPYBOOK, SCREEN_CALLS_PROGRAM, JOB_RUNS_PROGRAM, HANDLES_EVENT.

-Steps-
1. Identify all entities. For each identified entity, extract:
- entity_name: the artifact/identifier name, capitalized (e.g. CUSTMGMT, CUSTOMER-FILE).
- entity_type: One of: [{entity_types}]
- entity_description: what the entity is and what it does, grounded in the source.
Format: ("entity"<|><entity_name><|><entity_type><|><entity_description>)

2. Identify all pairs of (source_entity, target_entity) that are clearly related (a dependency).
For each, extract:
- source_entity: name of the source entity from step 1
- target_entity: name of the target entity from step 1
- relationship_description: START with the dependency label (CALLS / READS_FROM / WRITES_TO /
  USES_COPYBOOK / SCREEN_CALLS_PROGRAM / JOB_RUNS_PROGRAM / HANDLES_EVENT), then a short justification.
- relationship_strength: integer 1-10 for how strong/certain the dependency is.
Format: ("relationship"<|><source_entity><|><target_entity><|><relationship_description><|><relationship_strength>)

3. Return a single list of all entities and relationships. Use **##** as the list delimiter.

4. When finished, output <|COMPLETE|>

Example 1:
Entity_types: program,screen,copybook,datastore
Text:
Artifact: CUSTMGMT.CBL
Artifact type: COBOL program

       PROGRAM-ID. CUSTMGMT.
       SELECT CUSTOMER-FILE ASSIGN TO CUSTFILE ORGANIZATION IS INDEXED.
       FD  CUSTOMER-FILE.
           COPY CUSTREC.
       PROCEDURE DIVISION.
           DISPLAY "CUSTOMER MAINTENANCE".
           ACCEPT WS-OPTION.
           READ CUSTOMER-FILE.
           REWRITE CUSTOMER-RECORD.
           CALL 'ACCTPOST' USING CUST-ID.
######################

##
("entity"<|>CUSTREC<|>copybook<|>Shared copybook defining the customer record layout, included by CUSTMGMT)
##
("entity"<|>ACCTPOST<|>program<|>Account posting program invoked by CUSTMGMT)
##
("entity"<|>CUSTMGMT-SCREEN<|>screen<|>Interactive DISPLAY/ACCEPT dialog driving the CUSTMGMT program)
##
("relationship"<|>CUSTMGMT<|>CUSTOMER-FILE<|>READS_FROM and WRITES_TO: CUSTMGMT reads and rewrites records in CUSTOMER-FILE<|>9)
##
("relationship"<|>CUSTMGMT<|>CUSTREC<|>USES_COPYBOOK: CUSTMGMT includes the CUSTREC copybook to define its record layout<|>8)
##
